# `omarchy pkg add`. The AUR is not used: omarchy's own repository carries what
# it needs, so a package missing from it is either left out or fetched by
# another script (see the notes at the bottom).

# lazygit mise neovim ripgrep starship zoxide docker tmux ...) are left out, and
